# design-skills

Design skills for Claude Code, collected in `.claude/skills/`. They load automatically when Claude Code runs in this repository.

Sources:
- https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- https://github.com/Leonxlnx/taste-skill
- https://github.com/pbakaus/impeccable
- https://github.com/nutlope/hallmark
- https://github.com/Dammyjay93/interface-design

Original licenses are in `licenses/`.

## MCP servers

`.mcp.json` adds the [Playwright MCP](https://github.com/microsoft/playwright-mcp) server, so Claude can open pages in a browser, click through them and take screenshots. Claude Code asks you to approve project MCP servers the first time.
